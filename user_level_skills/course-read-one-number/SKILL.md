# Habit 2: read one number aloud

1. Choose one number from the figure or the table (the largest, or the one
   the text uses most).
2. Write it as one sentence that says: who, where, when, which unit, and how
   many people the number is based on, if the source says so.
   Template: "In <when>, <value> <unit> of <who> in <where> <what>
   (<who made the numbers>, <table or page>)."
3. Find the same number in the raw data file. Write the file name and row.
4. Same number? Write "match". Different? Stop and tell the user.
5. Add the sentence and the result to `outputs/checks.md`.
