# Habit 3: which script made it?

1. List every number in the figure, table or text the user names.
2. For each number, find the script that made it and the output file it is in.
3. A number with no script (typed by hand, or written by the agent in the
   chat): mark it "no script" and tell the user.
4. Run the scripts again, in order. Did any output number change? Report it.
5. Add the list to `outputs/checks.md`: number, script, output file, status.
