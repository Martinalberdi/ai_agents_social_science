# Habit 5: clear the desk

1. Write `docs/handover.md` (replace the old one):
   - what was done (with file names);
   - what is next (one small step);
   - open questions for the user.
2. Tell the user: "Start a new conversation and ask it to read
   docs/handover.md first."
