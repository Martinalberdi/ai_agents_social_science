# Before sharing: one command, three habits

1. If you can start a helper agent, give steps 2-4 to a helper agent, so the
   checks are done with a clean desk by an agent that did not do the work.
2. Habit 1: use the skill course-who-made-the-numbers on every source.
3. Habit 2: use the skill course-read-one-number on the main figure.
4. Habit 3: use the skill course-which-script on the main figure and text.
5. Write `outputs/before_sharing.md`: one line per habit, with a status
   (green = done and correct, amber = done with a warning, red = a problem),
   and what the user must decide.
6. Do not share, send or publish anything. The user decides.
