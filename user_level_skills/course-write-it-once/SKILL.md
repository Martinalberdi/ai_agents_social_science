# Habit 4: write it once, in the instruction file

1. Read the conversation and the project's instruction file.
2. List every decision taken in this session that is not yet in the
   instruction file (definitions, countries, years, what to leave out).
3. Show the list to the user. Add only the decisions the user approves,
   under one heading "Decisions", one line each.
4. Never change existing rules without asking.
